\section{Question 4: Machine Translation}

\subsection{Dataset Description}

Question 4 uses the English-to-German Multi30k translation benchmark \cite{elliott2016multi30k}. In the final run used here, the dataset is taken from its Hugging Face mirror and evaluated on the full exported split sizes: 29{,}000 training examples, 1{,}014 validation examples, and 1{,}000 test examples. This makes Q4 a full-data short-caption translation study rather than a tiny matched-slice comparison.

\subsection{Preprocessing and Model}

The finished Q4 model is a custom encoder-decoder with additive attention \cite{bahdanau2015nmt}. It uses a bidirectional GRU encoder, a GRU decoder, 256-dimensional token embeddings, hidden size 512, dropout 0.3, batch size 32, learning rate \(5 \times 10^{-4}\), gradient clipping at 1.0, teacher forcing ratio 0.5, and a maximum decoded length of 64 tokens. Source and target casing are preserved, and the vocabularies are capped at 12{,}000 tokens with minimum frequency 2.

Evaluation uses BLEU, ChrF, METEOR, and BERTScore on both validation and test. BLEU gives a familiar n-gram precision view of translation quality, ChrF is more tolerant of inflectional and morphological variation, METEOR accounts for word order and partial matching, and BERTScore captures semantic similarity through contextual embeddings. Together, the four metrics provide a credible multi-faceted evaluation for the full-data seq2seq run.

\subsection{Results}

Table~\ref{tab:q4_overall_results} summarizes the final full-data seq2seq results. The model reaches validation/test BLEU 0.2680/0.2725, ChrF 0.5137/0.5214, METEOR 0.5367/0.5431, and BERTScore 0.8286/0.8291. These values are strong enough to show that the model has learned meaningful caption translation behavior, even though the absolute output quality is still visibly uneven on harder examples.

\subsection{Qualitative Analysis}

The qualitative examples show both the strengths and remaining weaknesses of the full-data seq2seq system. On validation example \texttt{validation\_1000}, the model exactly matches the reference translation, \textit{Eine Gruppe von Menschen läuft.} On test example \texttt{test\_988}, it again produces an exact translation: \textit{Ein Mann mit Sonnenbrille fährt auf einem Roller.} These examples show that the model handles short, common caption patterns well when the lexical mapping is familiar.

Harder examples still fail noticeably. On validation example \texttt{validation\_760}, the model degenerates into \textit{Personen fahren und und dem Gehsteig die die}, which loses most of the source meaning and repeats function words. On test example \texttt{test\_476}, the source sentence \textit{A rock concert is taking place.} collapses into \textit{Ein Bergsteiger macht}, which is fluent only in fragments and semantically incorrect. These failures show that the model still struggles with rarer compositions and longer-range target planning.

The exported attention artifact adds a useful interpretability view. Figure~\ref{fig:q4_attention_heatmap} shows that the model learns sensible alignments for core content words such as \textit{A man} \(\rightarrow\) \textit{Ein Mann} and \textit{orange hat} \(\rightarrow\) \textit{orangefarbenen Hut}. The same attention example also exposes a residual decoding weakness: the final prediction, \textit{Ein Mann mit einem orangefarbenen Hut etwas.}, is close to the source meaning but still drops the phrase corresponding to \textit{staring at}.

\subsection{Discussion}

The Q4 evidence supports a narrower but cleaner conclusion than the earlier capped comparison. With full-data training, the custom seq2seq-plus-attention model learns a usable translation mapping for short caption data and produces exact or near-exact outputs on easy examples. It is therefore no longer just a failure baseline; it is a real, interpretable translation system with stable held-out metrics.

At the same time, the qualitative failures make it clear that the model is not yet robust across the full caption distribution. The final report claim for Q4 should therefore emphasize competent full-data seq2seq learning, visible attention alignment, and remaining brittleness on harder source sentences. A natural next step would be a full-data pretrained or fine-tuned transformer run on the same splits so that the recurrent baseline can be compared against a stronger reference under matched evaluation conditions.
